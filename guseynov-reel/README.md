# Guseyn Guseynov — biggest pop star

A 15-second motion graphics showreel (1920×1080, 30 fps) built with Remotion.
Standalone project — it uses Remotion from npm, not the monorepo packages.

Scenes: name slam intro → "THE BIGGEST POP STAR" kinetic typography → stat cards → world tour vinyl + equalizer → star finale with confetti.

```bash
npm i
npm run dev      # preview in Remotion Studio
npm run render   # out/guseynov-reel.mp4
```

In sandboxes where Remotion can't download Chrome, pass a local one:
`npm run render -- --browser-executable=/path/to/headless_shell`

Audio is generated by `scripts/make_audio.py`:
- voiceover: [Kokoro TTS](https://github.com/thewh1teagle/kokoro-onnx) (Apache-2.0), American female voice `af_bella` → `public/voice/*.wav`
- music: a 120 BPM pop track synthesized with numpy (kick, clap, hats, bass, supersaw pad, arp, riser, whooshes on the cuts), ducked under the voice → `public/music.wav`
- line timings → `src/audio-timeline.json`

To regenerate, put `kokoro-v1.0.int8.onnx` and `voices-v1.0.bin` from the kokoro-onnx releases into `.tts-models/`, then run `pip install kokoro-onnx soundfile scipy && python3 scripts/make_audio.py`.

Fonts (Anton, Inter — SIL OFL) are bundled in `public/fonts` so rendering works offline.
